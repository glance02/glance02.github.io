## NetworkX 简介

NetworkX 是 Python 中用于创建、操作和分析复杂网络/图结构的核心库，广泛应用于社交网络分析、路由算法、生物信息学等领域。
它可以用来实现[[信息传播模型]]仿真、[[影响力最大化问题]]的启发式种子选择，以及[[反向可达集]]采样实验。

---

## 常用函数

### 图的创建

| 函数                  | 说明        |
| ------------------- | --------- |
| `nx.Graph()`        | 无向图       |
| `nx.DiGraph()`      | 有向图       |
| `nx.MultiGraph()`   | 允许多重边的无向图 |
| `nx.MultiDiGraph()` | 允许多重边的有向图 |

### 节点与边操作

| 函数                       | 说明      |
| ------------------------ | ------- |
| `G.add_node(n)`          | 添加单个节点  |
| `G.add_nodes_from(list)` | 批量添加节点  |
| `G.add_edge(u, v)`       | 添加边     |
| `G.add_edges_from(list)` | 批量添加边   |
| `G.remove_node(n)`       | 删除节点    |
| `G.remove_edge(u, v)`    | 删除边     |
| `G.nodes()`              | 返回所有节点  |
| `G.edges()`              | 返回所有边   |
| `G.neighbors(n)`         | 返回节点的邻居 |

### 图的属性与信息

| 函数                    | 说明     |
| --------------------- | ------ |
| `G.number_of_nodes()` | 节点数量   |
| `G.number_of_edges()` | 边数量    |
| `G.degree(n)`         | 节点的度   |
| `nx.is_connected(G)`  | 判断是否连通 |
| `nx.density(G)`       | 图的密度   |

### 路径与连通性

|函数|说明|
|---|---|
|`nx.shortest_path(G, u, v)`|最短路径|
|`nx.shortest_path_length(G, u, v)`|最短路径长度|
|`nx.all_pairs_shortest_path(G)`|所有节点对的最短路径|
|`nx.connected_components(G)`|所有连通分量|
|`nx.has_path(G, u, v)`|判断两节点间是否有路径|

### 中心性分析

|函数|说明|
|---|---|
|`nx.degree_centrality(G)`|度中心性|
|`nx.betweenness_centrality(G)`|介数中心性|
|`nx.closeness_centrality(G)`|接近中心性|
|`nx.pagerank(G)`|PageRank 值|
|`nx.eigenvector_centrality(G)`|特征向量中心性|

### 图生成器（内置经典图）

| 函数                                         | 说明          |
| ------------------------------------------ | ----------- |
| `nx.complete_graph(n)`                     | 完全图         |
| `nx.cycle_graph(n)`                        | 环形图         |
| `nx.path_graph(n)`                         | 路径图         |
| `nx.random_graphs.erdos_renyi_graph(n, p)` | 随机图         |
| `nx.barabasi_albert_graph(n, m)`           | 无标度网络       |
| `nx.karate_club_graph()`                   | 经典空手道俱乐部数据集 |

### 可视化

|函数|说明|
|---|---|
|`nx.draw(G)`|基础绘图（配合 matplotlib）|
|`nx.draw_networkx(G)`|带标签的绘图|
|`nx.spring_layout(G)`|弹簧布局算法|
|`nx.circular_layout(G)`|环形布局|
