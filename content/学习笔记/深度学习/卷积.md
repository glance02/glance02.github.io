可以把卷积理解成一个“拿着小模板在图上滑动并打分”的过程。

假设有一张灰度图片，本质上是一个数字矩阵：

```
图片（输入）
1  2  0
3  1  2
0  1  3
```

再准备一个 `2×2` 的卷积核，也叫过滤器：

```
卷积核
1  0
0  1
```

卷积核先覆盖输入左上角的 `2×2` 区域：

```
输入局部        卷积核
1  2           1  0
3  1           0  1
```

对应位置相乘再求和：

```
1×1 + 2×0 + 3×0 + 1×1 = 2
```

这就得到输出特征图左上角的一个数。然后卷积核向右滑一步、向下滑一步，重复计算，形成新的矩阵。

---

卷积核里的数字决定它关注什么。

例如，一个卷积核可以对“左亮右暗”产生强响应，因而检测垂直边缘；另一个可能对“上亮下暗”敏感，用于检测水平边缘。网络训练时不需要你手工设计这些数，卷积核中的数值会通过训练自动学出来。

所以卷积层并不是“把图片压缩一下”，而是在回答：

> 图片的每个局部位置，是否出现了某种特征？

第一层通常学到边缘、颜色变化等简单模式；更深层把前面得到的特征再做卷积，逐渐学到纹理、部件，乃至物体整体。

和你前面问的通道结合起来看：

```
输入 RGB 图片：3 个通道
        ↓
一个卷积核：k × k × 3
        ↓
融合 RGB 三个通道的信息
        ↓
得到 1 个输出特征图
```

如果卷积层有 `64` 个不同的卷积核，就会输出 `64` 个特征图。每一个特征图都代表网络从原图中找到的一类不同模式。

补充一个容易混淆的点：深度学习框架里叫“卷积”的操作，严格数学上多数实际实现更接近“互相关”，即卷积核滑动前不翻转。但在 CNN 语境中，大家仍习惯称它为卷积。
