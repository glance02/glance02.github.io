> 卷积中使用的单次乘法，仍然是普通的数字乘法；但是“哪些数字参与运算、乘完后怎样求和、最终得到什么形状”，与通常所说的矩阵乘法不同。

因此，**卷积不是矩阵乘法本身**，但卷积可以经过适当展开，转换成矩阵乘法来计算。

## 1. 为什么都叫“乘法”，结果却不一样？

“乘法”在不同上下文中可能指不同运算。区分它们时，要看三个问题：

1. 输入是什么形状？
2. 哪些元素彼此相乘？
3. 相乘后是否求和？沿哪个维度求和？

| 运算     | 常见写法                        | 元素如何配对       | 是否求和         | 常见用途       |
| ------ | --------------------------- | ------------ | ------------ | ---------- |
| 标量乘法   | $ab$                        | 两个数字相乘       | 否            | 缩放         |
| 逐元素乘法  | $A \odot B$                 | 相同位置相乘       | 否            | 门控、掩码、注意力  |
| 点积     | $\mathbf{x}^\top\mathbf{y}$ | 相同位置相乘       | 全部求和         | 相似度、神经元加权和 |
| 矩阵乘法   | $AB$                        | 行与列做点积       | 沿公共维度求和      | 全连接层、线性变换  |
| 卷积/互相关 | $X * K$                     | 局部区域与卷积核对应相乘 | 对局部区域及输入通道求和 | 提取局部特征     |

它们的最小计算单元都可能包含普通的数字乘法，例如 $2\times3=6$。区别主要在于这些小乘法被怎样组织起来。

## 2. 标量乘法

标量就是单个数字，例如：

$$
3\times4=12
$$

标量与矩阵相乘时，通常表示每个元素都乘以这个标量：

$$
2\begin{bmatrix}1&3\\4&5\end{bmatrix}
=\begin{bmatrix}2&6\\8&10\end{bmatrix}
$$

这是一种整体缩放，不改变输入形状。

对应的 PyTorch 代码：

```python
import torch

scalar_result = torch.tensor(3) * torch.tensor(4)
print(scalar_result)  # tensor(12)

A = torch.tensor([
    [1, 3],
    [4, 5],
])
result = 2 * A
print(result)
# tensor([[ 2,  6],
#         [ 8, 10]])
```

## 3. 逐元素乘法（Hadamard product）

两个形状相同的矩阵，对应位置分别相乘：

$$
A=\begin{bmatrix}1&2\\3&4\end{bmatrix},\qquad
B=\begin{bmatrix}5&6\\7&8\end{bmatrix}
$$

$$
A\odot B=
\begin{bmatrix}
1\times5&2\times6\\
3\times7&4\times8
\end{bmatrix}
=\begin{bmatrix}5&12\\21&32\end{bmatrix}
$$

逐元素乘法有两个特点：

- 不把不同行、不同列的数据混合起来；
- 通常保持原来的形状。

在 PyTorch 和 NumPy 中，`A * B` 通常表示逐元素乘法，而不是线性代数中的矩阵乘法。

对应的 PyTorch 代码：

```python
import torch

A = torch.tensor([
    [1, 2],
    [3, 4],
])
B = torch.tensor([
    [5, 6],
    [7, 8],
])

result = A * B
# 等价写法：result = torch.mul(A, B)

print(result)
# tensor([[ 5, 12],
#         [21, 32]])
```

## 4. 向量点积

点积先让两个向量的对应元素相乘，再把结果全部相加：

$$
\mathbf{x}=\begin{bmatrix}1\\2\\3\end{bmatrix},\qquad
\mathbf{y}=\begin{bmatrix}4\\5\\6\end{bmatrix}
$$

$$
\mathbf{x}^\top\mathbf{y}=1\times4+2\times5+3\times6=32
$$

输入是两个向量，输出是一个标量。一个神经元所做的加权求和，本质上就是点积再加偏置：

$$
z=\mathbf{w}^\top\mathbf{x}+b
$$

对应的 PyTorch 代码：

```python
import torch

x = torch.tensor([1, 2, 3])
y = torch.tensor([4, 5, 6])

result = torch.dot(x, y)
# 等价写法：result = x @ y

print(result)  # tensor(32)
```

神经元的“点积加偏置”可以写成：

```python
x = torch.tensor([1.0, 2.0, 3.0])
w = torch.tensor([0.5, -1.0, 2.0])
b = torch.tensor(0.1)

z = torch.dot(w, x) + b
print(z)  # tensor(4.6000)
```

## 5. 矩阵乘法

设 $A\in\mathbb{R}^{m\times n}$，$B\in\mathbb{R}^{n\times p}$。只有当 $A$ 的列数等于 $B$ 的行数时，才能计算：

$$
C=AB\in\mathbb{R}^{m\times p},\qquad
C_{ij}=\sum_{k=1}^{n}A_{ik}B_{kj}
$$

例如：

$$
\begin{bmatrix}1&2\\3&4\end{bmatrix}
\begin{bmatrix}5&6\\7&8\end{bmatrix}
=
\begin{bmatrix}
1\times5+2\times7&1\times6+2\times8\\
3\times5+4\times7&3\times6+4\times8
\end{bmatrix}
=\begin{bmatrix}19&22\\43&50\end{bmatrix}
$$

它与逐元素乘法的结果完全不同。矩阵乘法不是“对应位置相乘”，而是：

> 左矩阵的一行与右矩阵的一列做点积。

全连接层通常写成：

$$
Y=XW+b
$$

如果 $X$ 的形状是 `batch_size × input_features`，$W$ 的形状是 `input_features × output_features`，那么 $Y$ 的形状就是 `batch_size × output_features`。

对应前面数值例子的 PyTorch 代码：

```python
import torch

A = torch.tensor([
    [1, 2],
    [3, 4],
])
B = torch.tensor([
    [5, 6],
    [7, 8],
])

C = A @ B
# 等价写法：C = torch.matmul(A, B)
# 对两个二维矩阵还可写成：C = torch.mm(A, B)

print(C)
# tensor([[19, 22],
#         [43, 50]])
```

一批输入经过线性变换可以写成：

```python
batch_size = 32
input_features = 128
output_features = 64

X = torch.randn(batch_size, input_features)
W = torch.randn(input_features, output_features)
b = torch.randn(output_features)

Y = X @ W + b
print(Y.shape)  # torch.Size([32, 64])
```

## 6. 二维卷积到底做了什么？

先考虑只有一个通道的输入。假设输入局部区域和卷积核分别为：

$$
P=\begin{bmatrix}1&2\\3&4\end{bmatrix},\qquad
K=\begin{bmatrix}5&6\\7&8\end{bmatrix}
$$

卷积核在这个位置产生的一个输出值是：

$$
1\times5+2\times6+3\times7+4\times8=70
$$

可以把它拆成两步：

1. 局部区域与卷积核逐元素相乘；
2. 把所有乘积相加，得到一个数字。

即：

$$
\operatorname{sum}(P\odot K)=70
$$

卷积核在输入上滑动，每到一个位置都重复这套操作，最终得到一张输出特征图。

所以，卷积与普通矩阵乘法的直接区别是：

- 矩阵乘法让“行”和“列”做点积；
- 卷积让“当前局部区域”和“卷积核”做点积；
- 同一个卷积核会在所有空间位置重复使用，这叫**权重共享**。

只计算这个局部区域的 PyTorch 代码：

```python
import torch

P = torch.tensor([
    [1, 2],
    [3, 4],
])
K = torch.tensor([
    [5, 6],
    [7, 8],
])

result = torch.sum(P * K)
print(result)  # tensor(70)
```

使用 `Conv2d` 让卷积核在一张单通道图片上滑动：

```python
import torch
import torch.nn.functional as F

# Conv2d 输入形状为：批量数 × 输入通道数 × 高 × 宽
X = torch.tensor([[[
    [1.0, 2.0, 0.0],
    [3.0, 4.0, 1.0],
    [0.0, 1.0, 2.0],
]]])

# 权重形状为：输出通道数 × 输入通道数 × 核高 × 核宽
K = torch.tensor([[[
    [5.0, 6.0],
    [7.0, 8.0],
]]])

Y = F.conv2d(X, K, bias=None, stride=1, padding=0)
print(Y)
# tensor([[[[70., 46.],
#           [47., 49.]]]])
```

## 7. 严格地说，CNN 中常用的是互相关

数学中的二维卷积会先把卷积核在水平和垂直方向翻转，再滑动计算。严格卷积可写成：

$$
Y_{i,j}=\sum_u\sum_v X_{i+u,j+v}K_{-u,-v}
$$

深度学习框架通常不翻转卷积核，实际计算的是互相关：

$$
Y_{i,j}=\sum_u\sum_v X_{i+u,j+v}K_{u,v}
$$

因为卷积核参数是训练出来的，是否预先翻转通常不影响模型的表达能力。因此在 CNN 领域，大家仍习惯把互相关称为“卷积”。

下面的代码展示 `F.conv2d` 默认不会翻转卷积核：

```python
import torch
import torch.nn.functional as F

X = torch.tensor([[[
    [1.0, 2.0],
    [3.0, 4.0],
]]])
K = torch.tensor([[[
    [5.0, 6.0],
    [7.0, 8.0],
]]])

cross_correlation = F.conv2d(X, K)
true_convolution = F.conv2d(X, torch.flip(K, dims=(-2, -1)))

print(cross_correlation)  # tensor([[[[70.]]]])
print(true_convolution)   # tensor([[[[60.]]]])
```

## 8. 多通道卷积如何计算？

彩色图片通常有 RGB 三个输入通道。一个卷积核不能只是二维的，它必须在通道维度上与输入一样深。

假设：

- 输入 $X$ 的形状为 $C_{in}\times H\times W$；
- 一个卷积核 $K$ 的形状为 $C_{in}\times K_h\times K_w$；
- 输出中的一个空间位置为 $(i,j)$。

那么一个输出值为：

$$
Y_{i,j}=
\sum_{c=1}^{C_{in}}
\sum_{u=1}^{K_h}
\sum_{v=1}^{K_w}
X_{c,i+u,j+v}K_{c,u,v}+b
$$

也就是说：

1. 每个输入通道都有一片对应的卷积核权重；
2. 各通道分别做“局部逐元素相乘并求和”；
3. 再把所有通道的结果相加；
4. 最后加偏置，得到一个输出值。

如果需要 $C_{out}$ 个输出通道，就使用 $C_{out}$ 组不同的卷积核。完整权重张量的形状通常是：

$$
C_{out}\times C_{in}\times K_h\times K_w
$$

每一组卷积核生成一个输出特征图。

对应的 PyTorch 代码：

```python
import torch
import torch.nn.functional as F

batch_size = 2
input_channels = 3
output_channels = 4
height = width = 8
kernel_size = 3

X = torch.randn(batch_size, input_channels, height, width)
K = torch.randn(
    output_channels,
    input_channels,
    kernel_size,
    kernel_size,
)
b = torch.randn(output_channels)

Y = F.conv2d(X, K, bias=b, stride=1, padding=0)

print(K.shape)  # torch.Size([4, 3, 3, 3])
print(Y.shape)  # torch.Size([2, 4, 6, 6])
```

`Y[0, 0, 0, 0]` 可以手工验证为第一个样本左上角的局部区域，与第一个输出通道卷积核逐元素相乘并跨三个输入通道求和：

```python
local_region = X[0, :, 0:3, 0:3]
manual_value = torch.sum(local_region * K[0]) + b[0]

print(torch.allclose(manual_value, Y[0, 0, 0, 0]))  # True
```

## 9. 为什么卷积又能变成矩阵乘法？

可以把每个输入局部区域和卷积核都“拉直”成向量：

$$
\begin{bmatrix}1&2\\3&4\end{bmatrix}
\longrightarrow\begin{bmatrix}1&2&3&4\end{bmatrix}
$$

$$
\begin{bmatrix}5&6\\7&8\end{bmatrix}
\longrightarrow\begin{bmatrix}5\\6\\7\\8\end{bmatrix}
$$

此时局部卷积就变成一个向量点积：

$$
\begin{bmatrix}1&2&3&4\end{bmatrix}
\begin{bmatrix}5\\6\\7\\8\end{bmatrix}=70
$$

如果把输入中的所有局部区域都拉直并堆叠成一个大矩阵，就能一次性与拉直后的卷积核做矩阵乘法。这类转换常称为 `im2col`。

因此下面两句话可以同时成立：

- **从数学定义看**：卷积不是普通矩阵乘法；
- **从计算实现看**：卷积常常可以转化为矩阵乘法，以利用高度优化的矩阵运算硬件和库。

现代框架也可能使用直接卷积、Winograd、FFT 等算法，并不保证内部一定真的执行 `im2col`，但它们计算的是同一个卷积结果（忽略浮点数值误差）。

使用 `F.unfold` 实现 `im2col`，再用矩阵乘法完成卷积：

```python
import torch
import torch.nn.functional as F

X = torch.tensor([[[
    [1.0, 2.0, 0.0],
    [3.0, 4.0, 1.0],
    [0.0, 1.0, 2.0],
]]])
K = torch.tensor([[[
    [5.0, 6.0],
    [7.0, 8.0],
]]])

# columns 形状：批量数 × (输入通道数 × 核高 × 核宽) × 滑动位置数
columns = F.unfold(X, kernel_size=(2, 2))
flat_kernel = K.reshape(1, -1)

# 每一列是一个拉直后的局部区域。
Y_by_matmul = flat_kernel @ columns[0]
Y_by_matmul = Y_by_matmul.reshape(1, 1, 2, 2)

Y_by_conv = F.conv2d(X, K)
print(Y_by_matmul)
print(torch.allclose(Y_by_matmul, Y_by_conv))  # True
```

## 10. 1 × 1 卷积为什么很像全连接层？

`1 × 1` 卷积不混合相邻空间位置，只在每个像素位置混合通道信息。

假设某个像素位置有 $C_{in}$ 个输入通道值，若要得到 $C_{out}$ 个输出通道，那么：

$$
\mathbf{x}_{i,j}\in\mathbb{R}^{C_{in}},\qquad
\mathbf{y}_{i,j}=W\mathbf{x}_{i,j}+\mathbf{b},\qquad
W\in\mathbb{R}^{C_{out}\times C_{in}}
$$

这就是在每个空间位置分别应用同一个全连接层。关键区别是：同一个 $W$ 会在所有像素位置共享。

对应的 PyTorch 代码：

```python
import torch
import torch.nn.functional as F

X = torch.randn(2, 3, 8, 8)
W = torch.randn(4, 3)
b = torch.randn(4)

# 1 × 1 卷积权重需要形状：输出通道数 × 输入通道数 × 1 × 1
Y_by_conv = F.conv2d(X, W[:, :, None, None], bias=b)

# 把通道移到最后，对每个像素位置应用同一个线性变换。
Y_by_linear = X.permute(0, 2, 3, 1) @ W.T + b
Y_by_linear = Y_by_linear.permute(0, 3, 1, 2)

print(Y_by_conv.shape)  # torch.Size([2, 4, 8, 8])
print(torch.allclose(Y_by_conv, Y_by_linear, atol=1e-6))  # True
```

## 11. 矩阵乘法与卷积的核心对比

| 对比项 | 矩阵乘法 | 卷积 |
|---|---|---|
| 基本组合 | 行与列做点积 | 局部窗口与卷积核做点积 |
| 是否关注空间邻域 | 不天然表达“相邻位置” | 天然处理局部邻域 |
| 权重使用方式 | 每个连接位置通常有自己的权重 | 同一卷积核跨位置共享 |
| 参数量 | 全连接大尺寸输入时通常很多 | 由核大小和通道数决定，与图像尺寸无直接关系 |
| 输入形式 | 常见为向量或二维批量矩阵 | 常见为带通道的图像或特征图张量 |
| 常见用途 | 全局特征混合、线性映射 | 局部特征提取 |
| 能否互相转化 | — | 可展开为矩阵乘法 |

## 12. 容易混淆的代码写法

以 PyTorch 为例：

```python
A * B                 # 逐元素乘法
torch.mul(A, B)       # 逐元素乘法
A @ B                 # 矩阵乘法
torch.matmul(A, B)    # 矩阵乘法；高维输入还支持批量矩阵乘法
torch.mm(A, B)        # 两个二维矩阵相乘
torch.dot(x, y)       # 两个一维向量点积
torch.nn.Conv2d(...)  # 二维卷积层（实际采用互相关定义）
```

还要注意**广播（broadcasting）**：执行逐元素运算时，两个张量不一定必须形状完全相同。只要满足广播规则，较小的张量就会被逻辑上扩展。例如：

```python
X.shape == (32, 128)
b.shape == (128,)
Y = X + b
```

这里同一个偏置向量 `b` 被加到批次中的每个样本上。广播改变的是元素如何配对，不会把逐元素运算变成矩阵乘法。

## 13. 用一句话记住

- **逐元素乘法**：相同位置相乘，不求和；
- **点积**：相同位置相乘，再全部求和；
- **矩阵乘法**：左边的行与右边的列做点积；
- **卷积**：滑动的局部窗口与卷积核做点积，并跨输入通道求和；
- **卷积的实现**：可以转换成矩阵乘法，但概念上仍是局部连接与权重共享的运算。

看到一个“乘法”时，先不要只问“是不是乘法”，而要问：

> 哪些元素相乘？在哪些维度上求和？输出形状是什么？

只要回答了这三个问题，大多数深度学习中的张量运算就不会再混淆。
