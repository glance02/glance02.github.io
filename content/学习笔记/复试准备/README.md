## 三条绝对不能犯的错

1. 主动报微动脉瘤那一支的数字（0.8185 是假指标，0.6767 建立在错误的 ground truth 上，**这一支只讲方法、不报数字**）
2. 主动提 IDRiD 上那一版 DR 分级的 F1 0.7915（低于平凡基线，讲不出去）
3. 把三个任务的数据集混成一个（Arranged / DRIVE / IDRiD 是三条独立数据链）
