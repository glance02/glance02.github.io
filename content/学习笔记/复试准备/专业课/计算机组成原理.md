## 30 秒开场

> 组成原理讲的是一台机器怎么把程序跑起来：冯·诺依曼结构里指令和数据都放存储器，CPU 取指-译码-执行。我抓存储层次、指令流水线和 I/O 三种控制方式。

---

## ★1. 冯·诺依曼结构

五大部件：运算器、控制器、存储器、输入、输出。核心：**存储程序**，指令和数据同一存储空间，靠地址区分。

和哈佛结构对比：哈佛指令数据分开，现代 CPU 在 Cache 层常常是哈佛（I-Cache / D-Cache 分开），主存仍是冯氏。

性能：CPU 时间 ≈ 指令数 × CPI × 时钟周期。MIPS、FLOPS 是衍生指标，跨机器比较要小心。

---

## ★2. 数据表示：补码、浮点

- 无符号 / 原码 / 反码 / 补码。计算机加减用补码，因为同一套加法器，且 0 的表示唯一。
- 溢出：两个同号相加得到异号。
- IEEE 754 单精度：1 符号 + 8 阶码（移码）+ 23 尾数。规格化尾数隐藏 1。阶码全 0 是非规格化/0，全 1 是 Inf/NaN。

口述不必把 32 位编码手算一遍，除非老师给数字。

大小端：多字节整数在内存里低字节在低地址是小端。网络字节序是大端。

---

## ★3. Cache（高频）

CPU 快、主存慢，用 Cache 利用局部性：时间局部性（刚用过还用）、空间局部性（旁边很快用到）。

**映射**

| 方式 | 一块主存能去哪 | 冲突 | 比较器 |
| --- | --- | --- | --- |
| 直接映射 | 只能一行 | 多 | 少，便宜 |
| 全相联 | 任意行 | 少 | 多，贵 |
| 组相联 | 某一组内任意行 | 折中 | 折中 |

地址划分：标记 tag + 组号/行号 + 块内偏移。

**替换**：组内满了用 LRU / FIFO / 随机。直接映射不用替换策略（只有一个位置）。

**写策略**

- 写直达 write-through：同时写 Cache 和主存，常配写缓冲。
- 写回 write-back：只改 Cache，换出时若 dirty 再写主存。
- 写分配 vs 非写分配：写缺失时是否把块调入 Cache。

命中率、缺失代价决定有效访存时间：
`T_eff = T_hit + miss_rate × T_miss`（可推广到多层）。

---

## ★4. 虚拟存储器（和 OS 一起答）

CPU 发虚地址 → TLB / 页表 → 物理地址 → Cache / 主存。顺序不要说反：是先翻译再查 Cache（也有虚地址 Cache，本科默认物理 Cache）。

页大小常见 4KB。多级页表、TLB 缺失、缺页走 OS。

---

## ★5. 指令周期与流水线

一条指令：取指 IF → 译码 ID → 执行 EX → 访存 MEM → 写回 WB（五级是教学模型）。

流水线提高吞吐，不缩短单条指令延迟。加速比理想是段数，实际有冒险：

1. **结构冒险**：部件冲突，加资源或停滞。
2. **数据冒险**：RAW 最常见，用转发 forwarding、停滞、编译重排。
3. **控制冒险**：分支，用预测、延迟槽（老架构）。

流水线吞吐 ≈ 1 条/周期（满载）。有气泡就下降。

超标量：一周期发射多条。乱序执行、寄存器重命名是后续课内容，能点名即可。

---

## ★6. 中断、DMA、程序查询

I/O 控制三种：

| 方式 | CPU 介入 | 适用 |
| --- | --- | --- |
| 程序查询 | 一直轮询 | 简单、慢设备 |
| 中断 | 设备就绪才打断 CPU，数据还常由 CPU 搬 | 中等速度 |
| DMA | CPU 只设参数，DMA 控制器搬块数据，结束再中断 | 磁盘、网卡 |

中断过程：关中断 / 保存断点与现场 / 识别中断源 / 开中断（是否嵌套看设计）/ 执行服务 / 恢复。

DMA 和 CPU 抢总线：周期挪用、交替访存、DMA 独占。

## ★7. 总线

按传送：数据、地址、控制。按层次：片内、系统、通信。

仲裁：链式查询简单不公平；计数器查询可改优先级；独立请求快、线多。

带宽 = 总线宽度 × 频率 × 传输效率。突发传输一次地址多次数据。

---

## 8. 指令系统

CISC vs RISC：RISC 指令规整、Load/Store、利于流水线。ARM、RISC-V 是 RISC；x86 对外 CISC，内部微码/微操接近 RISC。

寻址：立即、寄存器、直接、间接、偏移（相对、变基、变址）。
