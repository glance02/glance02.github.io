## ★1. 数组 vs 链表

| | 数组（顺序表） | 链表 |
| --- | --- | --- |
| 访问第 i 个 | O(1) | O(n) |
| 插入/删除 | 可能要挪元素 O(n) | 改指针，找到位置后 O(1) |
| 空间 | 连续，可能预分配浪费或扩容 | 额外存指针 |
| cache | 友好 | 不友好 |

扩容通常倍增，均摊 O(1)。面试别说「链表插入一定比数组快」——没找到位置之前都是 O(n)。

### 追问：反转单链表

三个指针 `prev, curr, next`：保存 next，把 curr 指回 prev，三人一起前移。注意空表和单节点。递归也能做，空间 O(n)。

## ★2. 栈和队列

- 栈：后进先出。括号匹配、函数调用、表达式求值、DFS 可用栈。
- 队列：先进先出。BFS、生产者-消费者。
- 循环队列判空：`front == rear`；判满：`(rear+1)%n == front`（浪费一个格子）或另用 size 计数。

**单调栈 / 优先队列** 面试很爱问。优先队列通常用堆实现。Dijkstra 的「每次取当前最短」就是最小堆，不是对数组快排。

---

## ★3. 树：遍历、BST、AVL、红黑、B/B+

**二叉树遍历**

- 前序：根左右；中序：左根右；后序：左右根。递归最清楚，非递归用栈，层序用队列。
- 前序+中序、后序+中序可以还原树；只有前序+后序一般不行（除非是满二叉树等特殊情况）。

**BST**：左 < 根 < 右。中序有序。删除分三种：叶子直接删；一个孩子，孩子顶上；两个孩子，用后继（右子树最小）或前驱替换再删后继。

**AVL**：平衡因子 -1/0/1。失衡四种：LL / RR 单旋，LR / RL 双旋。查找更稳，插入删除旋转多。

**红黑树**：近似平衡，插入删除旋转更少。STL `map/set`、Java 8 HashMap 链表过长后的树化，常用红黑树。性质口述四条就够：根黑、红节点孩子为黑、任意路径黑高相同、空叶子视为黑。

**B 树 / B+ 树**：多路平衡树，降低磁盘 I/O。B+ 树数据只在叶子、叶子有序链表串起来，范围查询更好，数据库索引常用 B+。

对比一句：内存里的有序映射常用红黑；磁盘上的索引常用 B+。

## ★4. 堆

完全二叉树，用数组存。小根堆：父 ≤ 子。

- 插入：放末尾上浮，O(log n)
- 删除堆顶：末尾填顶再下沉，O(log n)
- 建堆：从最后一个非叶下沉，O(n)

用途：优先队列、堆排序、Top-K、Dijkstra 的待选节点。

堆排序：建大顶堆，反复把堆顶和末尾交换再缩小堆。O(n log n)，不稳定，原地。

## ★5. 图：邻接矩阵 vs 邻接表；DFS / BFS

| | 邻接矩阵 | 邻接表 |
| --- | --- | --- |
| 空间 | O(V²) | O(V+E) |
| 查边 u→v | O(1) | O(度数) |
| 适合 | 稠密图 | 稀疏图 |

DFS：一条路走到底，回溯。判环、拓扑、连通分量。递归或栈。

BFS：层序。无权最短路、层次。队列。

拓扑排序：有向无环图。Kahn：入度为 0 入队；或 DFS 结束时间反序。有环则失败。

最小生成树：Prim（堆优化像 Dijkstra）、Kruskal（边排序 + 并查集）。

最短路见 [算法导论.md](算法导论.md) 的 Dijkstra。

## ★6. 哈希表与冲突

哈希：关键字 → 槽位，期望 O(1)。

冲突处理：

1. **链地址法**：槽上挂链表；Java HashMap 链表长了改红黑树。
2. **开放寻址**：线性探测、二次探测、双重哈希。删除要用墓碑标记。
3. **再哈希**：多个哈希函数。

装填因子过大要扩容（通常 2 倍）再 rehash。口述：扩容不是把链表原样搬，要按新容量重算下标。

好的哈希： Avalanche、均匀。字符串可以用多项式滚动哈希，注意模数。

## 7. 排序算法对比（湖大会点名快排、冒泡）

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 冒泡 | O(n²) | O(n²) | O(1) | 是 | 可加 flag，有序时 O(n) |
| 插入 | O(n²) | O(n²) | O(1) | 是 | 小数组、基本有序很快 |
| 选择 | O(n²) | O(n²) | O(1) | 否 | 交换次数少 |
| 快排 | O(n log n) | O(n²) | O(log n) | 否 | 实践最快之一 |
| 归并 | O(n log n) | O(n log n) | O(n) | 是 | 外排序基础 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 否 | 最坏也稳 |
| 计数/桶/基数 | O(n+k) 等 | — | 额外空间 | 看实现 | 关键字有范围时 |

**快排过程（必须能讲）：** 选 pivot，分区让左边 ≤ pivot ≤ 右边，两边递归。

**最坏：** 每次选到极值，有序数组 + 固定取第一个，退化 O(n²)。

**改进：** 随机 pivot 或三数取中；小区间改插入排序；三路快排处理大量重复；内省排序（快排过深切堆排）。

**冒泡改进：** 一趟无交换就停；记录最后交换位置，下一趟只排到那里。

稳定：关键字相等时相对顺序不变。需要稳定选归并；要原地且平均快选快排。

## 8. 查找

- 顺序 O(n)
- 有序数组二分 O(log n)，前提随机访问
- BST 平均 O(log n)，退化成链 O(n)
- 平衡树 / 跳表 O(log n)
- 哈希期望 O(1)，最坏 O(n)，不支持范围

KMP：字符串匹配，失配时用 next 数组跳过，O(n+m)。面试能说「避免主串指针回退」即可，next 怎么推如果要现场推，先写「最长真前后缀」。
