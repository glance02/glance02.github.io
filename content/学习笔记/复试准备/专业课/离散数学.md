## ★1. 命题逻辑与谓词

- 联结词：¬ ∧ ∨ → ↔。真值表。
- 等价：德摩根、分配、蕴含等式 `p→q ≡ ¬p ∨ q`。
- 永真 / 可满足 / 矛盾。
- 谓词：量词 ∀ ∃。否定时量词对偶：`¬∀x P(x) ≡ ∃x ¬P(x)`。
- 推理：三段论、假言推理。计算机里对应布尔满足、类型系统、规约。

面试别把「充分」「必要」说反：p→q 时 p 是 q 的充分，q 是 p 的必要。

---

## ★2. 集合、关系、函数

- 集合运算：并交补差幂集。|A∪B|=|A|+|B|-|A∩B|。
- 关系：笛卡尔积的子集。性质：自反、对称、反对称、传递。
- 等价关系 = 自反+对称+传递 → 划分。
- 偏序 = 自反+反对称+传递。Hasse 图。全序是可比的偏序。
- 函数：单射、满射、双射。有限集 |A|=|B| 时三者等价。

闭包：自反闭包加对角线；对称加反向边；传递做 Floyd 式可达（Warshall）。

## ★3. 图论（最容易被接到算法）

- 无向 / 有向；简单图；度。握手引理：度之和 = 2|E|。
- 连通、连通分量；有向：强连通、弱连通。
- 树：无环连通。n 顶点 n-1 边。唯一路径。
- 欧拉图：经过每条边恰好一次。无向：连通且度全偶。
- 哈密顿：经过每个顶点恰好一次。判定是 NP 完全，没有简单充要（不要编）。
- 二分图：顶点可二着色。最大匹配：匈牙利 / 网络流。
- 平面图：欧拉公式 v-e+f=2（连通平面）。

最短路、MST、拓扑见 [算法导论.md](算法导论.md)。

## 4. 组合与计数

- 排列 P、组合 C。二项式定理。
- 容斥原理。
- 鸽巢原理：n+1 个鸽子 n 个巢，必有一巢至少 2。加强版：保证某巢 ≥k。
- 递推：Fibonacci，生成函数点到即可。
