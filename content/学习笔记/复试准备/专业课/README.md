# 专业课面试速记（计算机科学与技术）

> 用法：不是教材，是**口述稿**。每门课先看「30 秒开场」和标 ★ 的题；进考场前只翻本页的「开口策略」。
>
> 湖大推免专业课出现频率偏低，但抽到就是冷箭。历年真题里出现过：TCP 可靠传输、Dijkstra 用什么结构、快排/冒泡、C 指针。老师也常问「哪些课学得好」，再顺着追问。

## 怎么开口（成绩口径）

| 课程 | 成绩 | 面试策略 |
| --- | ---: | --- |
| 高等数学 A（1）/（2） | 98 / **100** | 可主动提「数学基础」；不要展开成高数计算题 |
| 数据结构实验 | **100** | 理论课 81，实验满分：强调**动手实现**，不要装理论课学得最好 |
| 概率论与数理统计 | **99** | 可主动提；立刻接到美赛贝叶斯 / MCMC |
| 线性代数 | 95 | 可接到神经网络、特征值、SVD |
| 编译技术 | 93 | 专业课里分数最高之一，适合作为「学得比较系统」的例子 |
| 离散数学 | 92 | 图论、逻辑可接到算法 |
| 电路与数字系统 | 92 | 一般不主动提，除非问硬件 |
| 操作系统 | 88 | 408 必备，核心概念要能讲 |
| 算法导论 | 87 | 和数据结构一起准备 |
| 计算机组成原理 | 86 | Cache / 流水线 / 中断 DMA 要能讲 |
| 人工智能基础 | 85 | 立刻接到大创：过拟合、迁移学习、指标 |
| 图像处理与计算机视觉 | 87 | 立刻接到 VisionFM / 分割 / Dice |
| 软件工程 | 82 | 不主动提 |
| 数据结构（理论） | 81 | 不主动报分数；被问到：实验 100，项目里天天用 |
| 计算机网络 | 81 | **湖大真题出过 TCP**，必须能讲，即使分数一般 |
| 数据库原理 | 80 | 成绩单最低之一，不主动提；被问到坦承分数一般，把 ACID / 索引讲清楚 |

**老师问「哪些课学得好」推荐答法（约 20 秒）：**

> 数学基础比较扎实，高等数学有满分、概率论 99、线性代数 95。专业课里编译技术和操作系统、组成原理学得比较系统。数据结构理论课分数一般，但实验是满分，后面做眼底影像项目时链表、图、优先队列这些结构一直在用。

不要主动报网络 81、数据库 80。被问到就承认，并马上落到概念。

## 湖大专业课冷箭（必须能 60 秒讲完）

1. **TCP 怎么保证可靠传输** → [计算机网络.md](计算机网络.md)
2. **Dijkstra 里排序/选最小用什么** → 二叉堆（优先队列），不是快排
3. **快排过程、最坏情况、怎么改进** → [算法导论.md](算法导论.md)
4. **进程和线程的区别** → [操作系统.md](操作系统.md)
5. **Dice 和 IoU 的区别**（项目追问，也算专业课）→ [图像处理与计算机视觉.md](图像处理与计算机视觉.md)

## 答题铁律

1. **先给定义，再给例子，最后一句落地**。不要一上来堆名词。
2. **能接到项目就接一句**，但不要硬接。TCP 就别硬接到眼底影像。
3. **不会就 5 秒内开口**：「这个细节我记不准，我先说我理解的框架……」然后讲相邻概念。
4. **成绩单上的低分**：承认 → 说明后来怎么补 → 给一个正确概念。不要辩解「老师给分严」。
5. 老师追问「那复杂度呢 / 那最坏情况呢」时，说明你准备过；主动报复杂度，比等他问更好。
