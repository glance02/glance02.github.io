## ★1. 复杂度

- 大 O：上界；Ω 下界；Θ 紧界。面试默认说最坏时间。
- 比较的是增长阶，不是秒数。常数、低阶可略。
- 空间要说清是否算输入本身：原地算法额外 O(1) 或 O(log n)。
- 均摊：如动态数组扩容，单次 O(n)，均摊 O(1)。

主定理：`T(n)=aT(n/b)+f(n)`，比较 f 与 n^{log_b a}。能举归并 `T(n)=2T(n/2)+O(n) → Θ(n log n)` 即可。

---

## ★2. 快排（必须能讲过程）

1. 选 pivot。
2. 分区：小于的左，大于的右。
3. 两边递归。

- 平均 Θ(n log n)，最坏 Θ(n²)（已有序 + 固定取端点）。
- 额外空间平均 O(log n) 栈深，最坏 O(n)。
- 不稳定。

改进：随机 / 三数取中；小数组插入排序；三路划分（大量重复）；递归过深改堆排（introsort）。

和归并比：归并最坏也 n log n、稳定、要 O(n) 额外空间；快排 cache 更好，实践常更快。需要稳定或外排序用归并。

## ★3. Dijkstra 用什么结构（湖大真题）

朴素：每次在 V 里扫最小 dist，O(V²)，稠密图可以。

堆优化：待处理顶点放**最小堆（优先队列）**，按当前 dist 取顶。松弛时 decrease-key 或直接塞新二元组。

- 二叉堆：O((V+E) log V)
- 斐波那契堆理论上更优，面试说二叉堆即可

**不是快排，不是冒泡。** 老师若给选项「快排 / 堆 / 冒泡」，选堆。

限制：边权非负。有负权用 Bellman-Ford（可判负环），全点对用 Floyd。

和 Prim 很像：都是堆 + 贪心扩集合；Dijkstra 比的是到源点距离，Prim 比的是到树的边权。

BFS 是无权图（或等权）最短路，队列即可，不必堆。

## 4. 贪心 vs DP

贪心：每步局部最优，需证明交换论证或贪心选择性质。例：活动选择、Huffman、最小生成树、Dijkstra。

DP：重叠子问题 + 最优子结构。先定义状态，再转移，再边界。

背包口述：

- 0-1：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w]+v)`，可压成一维，**容量倒序**。
- 完全背包：一维正序。

最长公共子序列 LCS、最长递增子序列 LIS（O(n log n) 二分 + 贪心数组）是常考点。

面试被问「什么时候能 DP」：能把大问题拆成子问题，子问题会重复算，且子问题最优能拼出原问题最优。

---

## 5. 分治

把问题划成相似子问题，递归解，再合并。

例：归并、快排、最大子数组（也可 DP）、Karatsuba 乘法、最近点对。

和 DP 差在：分治子问题通常不重叠；重叠了就变成 DP（带备忘录的分治）。

## 6. 图算法清单

| 问题 | 算法 | 复杂度（口述） |
| --- | --- | --- |
| 遍历 | DFS / BFS | O(V+E) |
| 拓扑 | Kahn / DFS | O(V+E) |
| MST | Kruskal（边排序+并查集）、Prim | 约 O(E log E) |
| 单源最短路 | Dijkstra / Bellman-Ford | 堆优化 (V+E)log V / VE |
| 全源 | Floyd | O(V³) |
| 网络流 | Ford-Fulkerson / Dinic | 能点名即可 |

并查集：路径压缩 + 按秩合并，均摊近 O(1)。Kruskal 用它判是否成环。

## 8. 和美赛、大创怎么接

美赛：MCMC 是采样近似后验，不是最短路；但「用仿真比较规则」是算法思想——用计算换封闭解。

大创：训练本身是优化算法（SGD）；评估要自己写指标循环。复杂度上，滑窗 patch 数量 ≈ 图大小 / stride²，这是空间换小目标召回。

不要把深度学习说成 Dijkstra。
