## 30 秒开场

> 操作系统我按四件事记：把 CPU 分给进程和线程、把内存虚实转换并保护、把磁盘组织成文件、把设备 I/O 调度好。核心抽象是进程，核心矛盾是并发下的同步互斥。

## ★1. 进程 vs 线程

| | 进程 | 线程 |
| --- | --- | --- |
| 是什么 | 资源分配的基本单位 | CPU 调度的基本单位（内核线程视角） |
| 地址空间 | 独立 | 同进程共享 |
| 开销 | 创建/切换大 | 小 |
| 通信 | IPC（管道、消息队列、共享内存、套接字、信号） | 直接读写共享变量，要加锁 |
| 崩溃 | 一般不影响其他进程 | 一个线程挂可能拖垮整个进程 |

补充：线程共享代码、数据、堆、打开文件；各自有栈、寄存器、程序计数器。

### 追问：协程呢？

用户态更轻量的调度单位，切换不陷入内核。适合高并发 I/O。不是 408 必考，知道「用户态、自愿让出」即可。

### 追问：用户级线程 vs 内核级线程

用户级：内核看不见，切换快，一个阻塞则进程内全堵。内核级：内核调度，一个堵不影响其他，开销更大。现代 OS 常见 1:1（NPTL）。

## ★2. 进程状态

就绪 → 运行：获得 CPU。
运行 → 就绪：时间片到，或被抢占。
运行 → 阻塞：等 I/O、锁、sleep。
阻塞 → 就绪：等待事件完成，**不能直接到运行**。

新建、终止另算。不要画出「阻塞直接到运行」。

## ★3. 调度算法

| 算法 | 要点 | 问题 |
| --- | --- | --- |
| FCFS | 来了就排 | 短作业等长作业 |
| SJF / 短作业优先 | 平均等待短 | 长作业饥饿；估计运行时间 |
| 优先级 | 可抢占/非抢占 | 饥饿，要老化 |
| RR 时间片轮转 | 交互公平 | 时间片太大≈FCFS，太小切换开销大 |
| 多级反馈队列 | 新作业高优先、时间片逐级变长 | Linux 早期思路之一 |

Linux 桌面/服务器常见 CFS：红黑树按 vruntime 排，跑得少的先跑。面试提到即可，不要假装读过内核源码。

实时：硬实时 vs 软实时。RMS、EDF 知道名字即可。

## ★4. 同步互斥、临界区、信号量

临界区：访问共享资源的那段代码。要互斥、空闲让进、有限等待。

**锁 / mutex**：同时只有一个持有者。

**信号量**：整型 + 等待队列。P（wait）减一，<0 则阻塞；V（signal）加一，可唤醒。

**生产者-消费者（口述 PV）：**

- 空槽 `empty = N`，满槽 `full = 0`，互斥 `mutex = 1`
- 生产者：P(empty) → P(mutex) → 放 → V(mutex) → V(full)
- 消费者：P(full) → P(mutex) → 取 → V(mutex) → V(empty)
- **P 的顺序不能反**：先 mutex 再 empty 可能死锁。

读者-写者：允许多读者，写者互斥。哲学家进餐：最多 4 人同时拿叉，或奇偶顺序，避免环路等待。

管程：语言级把锁和条件变量包起来，wait/signal。

## ★5. 死锁

四个必要条件（缺一不可）：

1. 互斥
2. 持有并等待
3. 不可抢占
4. 循环等待

处理：

- **预防**：破坏四个条件之一（例如一次性申请全部资源、资源有序申请）。
- **避免**：银行家算法，分配前检查是否进入不安全状态。
- **检测 + 解除**：资源分配图找环，然后剥夺或杀进程。
- **鸵鸟**：不管，重启。实际系统有时采用。

银行家：每个进程报最大需求，系统看剩余是否能让某个进程跑完并还回，能则安全。

饥饿 ≠ 死锁。饥饿是一直得不到；死锁是互相卡住。

## ★6. 虚拟内存、分页、缺页

为什么要虚拟内存：让进程觉得有连续大地址空间，实际映射到物理页，还能放磁盘上。隔离、方便加载、提高内存利用率。

**页表**：虚页号 → 物理页框 + 有效位、脏位、访问位。多级页表降低页表本身占用。TLB 缓存页表项。

**缺页**：访问无效页 → 缺页异常 → OS 找空闲框或换出一页 → 从磁盘读入 → 更新页表 → 重启那条指令。

抖动（thrashing）：缺页频繁，大部分时间在换页。原因是工作集大于物理内存。办法：降多道、工作集模型、加内存。

段页式：段提供逻辑模块，页提供固定块映射。

## ★7. 页面置换

| 算法 | 思想 | 备注 |
| --- | --- | --- |
| OPT | 换最久以后才用的 | 理想，无法预知 |
| FIFO | 换最早进来的 | 有 Belady 异常 |
| LRU | 换最久没访问的 | 近似最优，开销大 |
| Clock / 二次机会 | 扫描访问位 | LRU 的廉价近似 |

Belady：FIFO 有时页框越多缺页反而越多。LRU、OPT 没有。

和 Cache 替换是同一类问题，层次不同。

## 8. 用户态 / 内核态、系统调用

特权指令只能内核态执行。应用通过系统调用陷入内核（int / syscall），OS 完成后再返回。

切换代价：保存寄存器、改模式、可能刷 TLB（进程切换更重）。所以高并发要减少不必要的 syscall，I/O 用 epoll 等。

---

## 9. 文件与磁盘

逻辑结构：流式 / 记录式。物理：连续、链接、索引（inode 多级索引）。

目录：树。权限：用户-组-其他。

磁盘调度：FCFS、SSTF、SCAN、C-LOOK。SSTF 可能饥饿。

缓冲：减少 CPU 与设备速度差。单缓冲、双缓冲、缓冲池。

---

## 10. 中断、异常、系统调用（和计组交界）

- 中断：设备或时钟异步打断。
- 异常 / 陷入：指令执行中同步发生（缺页、除零、syscall）。
- 处理后回到被打断处（中断）或那条指令 / 下一条（取决于类型）。
